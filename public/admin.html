Chốc Chốc — Admin nội dung website

Cách dùng: Sửa nội dung bên trái → xem kết quả ngay bên phải. Khi xong, bấm “Tải file website” để lấy file HTML mới, thay vào file site cũ. Vì công cụ này không tự lưu, hãy bấm “Lưu dữ liệu (.json)” để giữ lại bản nháp, lần sau mở admin thì “Nhập dữ liệu” lại để tiếp tục chỉnh sửa.

Ảnh: mỗi mục ảnh có ghi chú kích thước chuẩn theo khung thiết kế của site — nên thiết kế/crop đúng tỉ lệ đó trước khi tải lên để ảnh không bị vỡ nét hay cắt sai bố cục. Bạn có thể dán link ảnh có sẵn hoặc bấm "Chọn ảnh từ máy" để đính kèm trực tiếp (ảnh sẽ được nhúng thẳng vào file, không cần host ở đâu khác — nhưng nếu dùng nhiều ảnh máy, file HTML xuất ra sẽ nặng hơn).
